ПОЛНЫЙ СПИСОК ФУНКЦИЙ САЙТА «ВОЛОНТЁРЫ БЕЛАРУСИ»
https://volunteers-belarus.vercel.app
==================================================

--------------------------------------------------
1. РЕГИСТРАЦИЯ И ВХОД
--------------------------------------------------
- Регистрация аккаунтов трёх ролей: Волонтёр, Организация, Администратор
- Вход и выход из аккаунта
- Чекбокс «Запомнить меня» — сессия сохраняется до 30 дней
- Проверка повторного пароля при регистрации
- Хранение паролей в зашифрованном виде (bcrypt)
- Защита страниц по ролям (volunteer / organizer / admin)
- Редирект на запрашиваемую страницу после входа

--------------------------------------------------
2. КАТАЛОГ ЗАЯВОК (для волонтёров)
--------------------------------------------------
- Просмотр всех открытых заявок на помощь
- Фильтры: категория помощи, город, поиск по названию
- Страница заявки: описание, дата и время, адрес, требования,
  контакты организатора, количество свободных мест
- Отклик на заявку с сопроводительным сообщением
- Попытка отклика на свою же организацию отклоняется
- Проверка заполненного профиля волонтёра перед откликом

--------------------------------------------------
3. ЛИЧНЫЙ КАБИНЕТ ВОЛОНТЁРА
--------------------------------------------------
- Статистика: всего откликов, на рассмотрении, одобрено, выполнено, часов помощи
- Вкладки: все / активные / выполненные / не явился
- Оценка организации после выполнения заявки (1–5 звёзд)
- Индикатор, что организация уже оценена
- Бейдж «Ненадёжный волонтёр» при пропусках (более 40% неявок)
- Автоматическое снятие бейджа при улучшении надёжности
- Компактные SVG-иконки вместо эмодзи
- Редактирование профиля волонтёра

--------------------------------------------------
4. ЛИЧНЫЙ КАБИНЕТ ОРГАНИЗАЦИИ
--------------------------------------------------
- Создание заявки на помощь (название, описание, категория, город,
  адрес, дата и время, количество мест, требования, контакты)
- Список созданных заявок с количеством откликов
- Управление откликами: одобрить / отклонить
- Отметить выполнение заявки и проставить часы волонтёру
- Отметить неявку волонтёра (влияет на его надёжность)
- Автоматический расчёт общего количества часов волонтёра
- Перенос события: изменение даты/времени заявки
  -> откликнувшиеся волонтёры получают уведомление
  -> волонтёры повторно подтверждают участие или отказываются
- Мониторинг заполненности мест (filledSlots)
- Редактирование профиля организации

--------------------------------------------------
5. СИСТЕМА РЕЙТИНГОВ И НАДЁЖНОСТИ
--------------------------------------------------
- Волонтёры оценивают организации после выполненной заявки
- На странице организации показывается средний рейтинг и число оценок
- Расчёт надёжности волонтёра (доля неявок среди завершённых заявок)
- Бейдж «Ненадёжный» виден организациям при выборе волонтёра
- Автоматический пересчёт доступен администратору
- Возможность оценить организацию и на отдельной странице /ocenit

--------------------------------------------------
6. УВЕДОМЛЕНИЯ
--------------------------------------------------
- Колокольчик с количеством непрочитанных уведомлений
- Список уведомлений с датой
- Отметить все как прочитанные
- Типы уведомлений:
  1) отклик одобрен организацией
  2) организация подтвердила выполнение
  3) волонтёр оценил организацию
  4) напоминание об отметке явки
  5) дата события изменена (перенос)
  6) волонтёр отказался после переноса даты

--------------------------------------------------
7. АДМИНИСТРАТОР
--------------------------------------------------
- Статистика платформы: пользователи, организации, волонтёры,
  заявки на помощь, отклики, ожидающие решения
- Верификация организаций (подтвердить / снять)
- Изменение статуса заявки на помощь (открыта / закрыта / завершена)
- Удаление любого аккаунта пользователя (кроме администраторов)
- Удаление любой организации вместе со всеми её заявками
- Управление новостями платформы (создание, редактирование, удаление)

--------------------------------------------------
8. НОВОСТИ И ИНФОРМАЦИОННЫЕ СТРАНИЦЫ
--------------------------------------------------
- Лента новостей платформы
- Страница отдельной новости по ссылке
- Страница «Как это работает» (инструкция для волонтёров и организаций)
- Страница «О проекте»
- Страница «Контакты»
- Главная страница категорий помощи с новостями

--------------------------------------------------
9. КАТЕГОРИИ ПОМОЩИ (SVG-иконки вместо эмодзи)
--------------------------------------------------
- Помощь пожилым
- Работа с детьми
- Экология
- Собаки и животные
- Бездомные люди
- Помощь при стихийных бедствиях
- Помощь больным
- Поиск без вести пропавших
- Юридическая помощь
- Бухгалтерская помощь
- Уборка и благоустройство
- Приюты и волонтёрские центры

--------------------------------------------------
10. ТЕХНИЧЕСКАЯ ЧАСТЬ
--------------------------------------------------
- Next.js (App Router) + React + TypeScript
- PostgreSQL (Neon) + Prisma ORM
- NextAuth (JWT-сессии)
- Zod-валидация форм
- Tailwind CSS (адаптивный дизайн, тёмных тонов нет, качественная вёрстка)
- Серверные экшены (Server Actions) вместо REST API
- Хэширование паролей
- Полностью без эмодзи в интерфейсе
- Деплой на Vercel
